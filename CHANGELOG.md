# Change Log

All notable changes to the "flutter-getx-template" extension will be documented in this file.

## [2.0.1]

### Changed

- Improve Marketplace metadata (display name, description, and keywords)
- Improve README documentation and usage guide
- Rename command title from **New GetX Template** to **New GetX Page**
- Optimize search keywords

## [2.0.0]

### Changed

- Update generated page template to include `const XxxPage({super.key});`

- Refresh README with a usage demo GIF and updated template example

## [0.0.1]

### Added

- Initial release
- Generate GetX `controller`, `binding`, and `page` files
- Support Explorer right-click menu
- Support Command Palette command
